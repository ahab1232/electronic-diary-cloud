# Платформа электронного дневника с облачным хранением и аналитикой

#Electronic Diary Cloud

Electronic Diary Cloud — это учебный проект по дисциплине «Разработка и сопровождение ИС», направленный на разработку информационной системы в сфере образования.
Проект представляет собой облачную электронную систему учета учебного процесса, предназначенную для хранения и анализа данных об успеваемости, расписании и взаимодействии между участниками образовательного процесса
 
Информационная система для управления учебным процессом
в образовательных учреждениях.

#Предметная область

Образование
Система ориентирована на использование в образовательных учреждениях (школы, колледжи, университеты).

# Цель проекта
Создание единой цифровой платформы для учета и просмотра успеваемости,
расписаний, заданий и взаимодействия участников в приложении обучения.

# Нефункциональные требования 
безопасность: хэширование паролей, роли/права доступа, защита от SQL-injection/XSS
производительность: “страница оценок загружается ≤ 2 сек при 5000 учеников”
надежность: резервное копирование, логирование ошибок
доступность: адаптивность под телефон, WCAG-база (контраст/шрифты)
конфиденциальность: кто что видит (родитель — только своего ребенка)

# Основной функционал (планируемый)
регистрация и авторизация пользователей;
управление учебными группами;
ведение электронного журнала;
учет оценок и посещаемости;
просмотр расписания;
хранение учебных материалов.

# Пользователи
- Школьник
- Преподаватель - оценивание 
- Администратор
- Родители 

 # Роли и права доступа 
- Ученик: смотрит оценки/дз/расписание
- Преподаватель: выставляет оценки/посещаемость/публикует ДЗ
- Админ: управляет пользователями, группами, предметами
- Родители: просмотр успеваемости, уведомления
